# Codebase Atlas

Interactive isometric map of this repo, built with the `codebase-atlas` skill.

- **Source:** `docs/atlas/atlas.html`
- **Measured against:** commit `cd97ea3` on `main`, 2026-09-04

The page is fully self-contained, so opening `docs/atlas/atlas.html` in a browser works with
no server. `bun run atlas` serves this directory at <http://localhost:8731/atlas.html> when
you need a real origin — which the Playwright checks below do, since they cannot load
`file://`.

## What it maps

Twenty structures across eight groups: the browser surfaces (pages, components, design
tokens), the eight feature modules, the eight route handlers and the app runtime behind them,
the schema and its two data stores, the Terraform root and its six modules, the delivery
pipeline and docs, and the agent harness — which is, by line count, the largest thing in the
repository and ships none of itself.

Four traces walk end to end: starting a drill and answering a question, typing an answer the
grader can't judge and self-grading it, finishing a run and acting on the summary, and
shipping a change to production.

## Updating it

`atlas.html` in this directory is the source of truth — edit it in place and reopen it. The
atlas is not published anywhere; it ships with the repo as a file.

Every number on the page comes from a scan of the working tree. If code changes, re-measure
before editing the `STRUCTURES` data block; never hand-adjust a count. Heights derive from
`loc` at runtime (`min(2.0, 0.35*sqrt(loc/100))`) — never hand-set a height.

The data blocks (`GROUPS`, `STRUCTURES`, `EXTERNALS`, `EDGES`, `TRACES`, `OVERVIEW_*`,
`STATS`, `ZONES`) are the only part worth editing by hand; everything after the
`===== rendering =====` marker is the engine and is independent of what this repo contains.

## How the numbers were measured

```bash
# per-subsystem source lines under apps/
find <dir> -type f \( -name '*.ts' -o -name '*.tsx' -o -name '*.css' \) | xargs wc -l

# infra/, .github/ and .claude/ use tracked files only, so build output and
# the git-ignored generated Prisma client are excluded
git ls-files <dir> | xargs wc -l
```

Excluded everywhere: `node_modules`, build output, and `apps/nextjs/prisma/generated`
(the Prisma client is git-ignored and regenerated by `db:generate`).

Two consistency rules the data must satisfy, both cheap to check by hand: a structure's
`children` line counts sum to its own `loc`, and no two footprints overlap in grid space.

## Scrub level: standard

The page deliberately contains **no** live-infrastructure identifiers. Cloud services are
described by role ("managed hosting platform", "managed serverless Postgres", "object
storage") rather than by product name in the prose. What is kept is code structure: Terraform
module _directory_ names, line counts, file counts and stack names.

Verified absent from `atlas.html`: the root domain, the org handle, any region, account ID,
ARN, bucket or secret name, environment variable name, email address, connection-string
prefix, the certification slug whose bank is loaded, and any external host other than Google
Fonts.

This matters because `atlas.html` is committed and this repo is public — anything that lands
here lands in git history. Re-run the sweep before committing a change to it:

```bash
grep -inE 'ahmax99|\.online|npg_|neon\.tech|GOCSPX|AKIA|arn:|amazonaws|ap-(north|south)east|DATABASE_URL|S3_BUCKET|lpic' atlas.html
grep -oE 'https?://[a-zA-Z0-9./-]+' atlas.html | sort -u   # expect only fonts.googleapis.com / fonts.gstatic.com / w3.org
```

> The question banks live in the repo-root `data/` directory, which is git-ignored. Do not
> read question content into an atlas scan — counts and structure only.

## Verifying a change

Playwright cannot load `file://`, so serve the directory first:

```bash
bun run atlas    # serves docs/atlas on :8731 — stop it when done
```

The page exposes `window.__atlas` (`setTrace`, `next`, `inside`, `city`, `stop`, plus the raw
data blocks), which is what makes this checkable without clicking. Confirm: zero console
errors, all four traces walk end to end with the step count the data declares, go-inside/back
works for every structure with a breakdown, the theme toggle survives mid-trace, reset does
not drift the view mid-pan, no zone caption sits over a block, and no horizontal page scroll
at 720px. Delete any screenshots afterwards — none belong in the repo.
