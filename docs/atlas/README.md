# Codebase Atlas

Interactive isometric map of this monorepo, built with the `codebase-atlas` skill.

- **Source:** `docs/atlas/atlas.html`
- **Measured against:** commit `c7d2297` on `main`, 2026-08-28

The page is fully self-contained, so opening `docs/atlas/atlas.html` in a browser works with
no server. `bun run atlas` serves this directory at <http://localhost:8731/atlas.html> when
you need a real origin — which the Playwright checks below do, since they cannot load
`file://`.

## Updating it

`atlas.html` in this directory is the source of truth — edit it in place and reopen it. The
atlas is not published anywhere; it ships with the repo as a file.

Every number on the page comes from a scan of the working tree. If code changes, re-measure
before editing the `STRUCTURES` data block; never hand-adjust a count. Heights derive from
`loc` at runtime (`min(2.0, 0.35*sqrt(loc/100))`) — never hand-set a height.

## How the numbers were measured

```bash
# per-subsystem source lines (apps/ and shared/)
find <dir> -type f \( -name '*.ts' -o -name '*.tsx' -o -name '*.css' \) | xargs cat | wc -l

# infra/, .github/, .claude/ use tracked files only, so build output and
# the git-ignored generated Prisma client are excluded
git ls-files <dir> | xargs cat | wc -l
```

Excluded everywhere: `node_modules`, build output, `shared/neon/src/generated`
(the Prisma client is git-ignored and regenerated by `db:generate`).

## Scrub level: standard

The page deliberately contains **no** live-infrastructure identifiers. Cloud services are
described by role ("managed identity provider", "transactional email service", "container
image registry", "delivery network") rather than by product name in the prose. What is kept
is code structure: Terraform module _directory_ names, line counts, file counts and stack
names.

Verified absent from `atlas.html`: the root domain, the org handle, any region, account ID,
ARN, bucket or secret name, cookie name, custom header name, environment variable name, email
address, API-key prefix, and any external host other than Google Fonts.

This matters because `atlas.html` is committed, and this repo is a public GitHub template —
anything that lands here lands in git history. Re-run the sweep before committing a change to
it:

```bash
grep -inE 'ahmax99|\.online|earlyref|npg_|neon\.tech|sentry\.io|resend|GOCSPX|AKIA|arn:|amazonaws|ap-(north|south)east|auth_session|auth_pkce|X-Id-Token|DATABASE_URL|SESSION_SECRET|COGNITO_' atlas.html
grep -oE 'https?://[a-zA-Z0-9./-]+' atlas.html | sort -u   # expect only fonts.googleapis.com / fonts.gstatic.com / w3.org
```

> `infra/vars/dev.tfvars` holds real secrets but is git-ignored (only `tfvars.example` is
> tracked). Do not read it into an atlas scan.

## Verifying a change

Playwright cannot load `file://`, so serve the directory first:

```bash
bun run atlas    # serves docs/atlas on :8731 — stop it when done
```

Then check: zero console errors, all three traces walk end to end, go-inside/back works for
every structure with a breakdown, the theme toggle survives mid-trace, reset does not drift
the view mid-pan, and no horizontal page scroll at 720px. Delete any screenshots afterwards —
none belong in the repo.
